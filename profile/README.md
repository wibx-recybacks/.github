# Recybacks

Marketplace de créditos de reciclagem por logística reversa, construído pelo
[Wibx Labs](https://github.com/Wibx-LABS).

Os repositórios desta organização são privados e o acesso é por convite. Este repositório
(`.github`) é o único público e guarda só os padrões de colaboração: templates de issue e de pull
request e a política de segurança.

## Como colaboramos

- Toda mudança entra por branch e pull request, revisada antes do merge. Nunca direto na `main`.
- Títulos em [conventional commits](https://www.conventionalcommits.org/), textos em português.
- Segredo, credencial e dado pessoal nunca entram no git.
- Vulnerabilidade se reporta em privado: veja [SECURITY.md](../SECURITY.md).
